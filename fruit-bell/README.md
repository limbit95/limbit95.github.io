# Fruit Bell 3D Prototype

`fruit-bell/`은 청파 같이 안에서 테스트 중인 1인칭 3D 반응형 카드 게임 프로토타입입니다.

## 현재 조작

- 내 카드 더미 위에서 마우스 왼쪽 버튼을 누른 채 위로 드래그하면 카드를 뒤집습니다.
- PC에서는 `Space`로 중앙 종을 칩니다.
- 모바일에서는 화면에 렌더링된 실제 3D 종을 직접 터치합니다.
- 마우스 이동으로 시선을 좌우/상하로 움직일 수 있습니다.

## 현재 규칙 프로토타입

- 과일은 딸기, 바나나, 라임, 자두 4종입니다.
- 각 과일별 카드 수량은 `[1, 1, 1, 2, 2, 3, 3, 4, 5]`입니다.
- 테이블 위에 공개된 같은 과일의 합계가 정확히 5가 되면 종을 칠 수 있습니다.
- 정답으로 종을 친 플레이어는 현재 공개 카드들을 자신의 뽑기 더미로 가져갑니다.
- 오답으로 종을 친 플레이어는 남아 있는 각 상대에게 최대 한 장씩 카드를 넘깁니다.
- 오답 패널티 후 뽑기 카드가 없으면 탈락합니다.
- 시각적 진행 방향은 `나 → 왼쪽 → 정면 → 오른쪽` 순서입니다.

현재 규칙은 상용 보드게임의 정확한 전체 카드 구성이나 모든 예외 규칙을 복제한 것이 아니라, 웹게임 상호작용과 멀티플레이 구조를 검증하기 위한 프로토타입입니다.

## 3D 표현

- Three.js 기반 1인칭 테이블 장면입니다.
- 중앙에는 물리적인 책상 종 형태의 3D 오브젝트가 있습니다.
- 상대는 현재 절차형 동물 아바타와 임시 리깅 파일럿을 사용합니다.
- 카드, 종, 손, 상대 캐릭터의 움직임은 게임 판정과 분리된 표현 계층에서 처리합니다.
- 최근 테이블 크기를 캐릭터 체형에 맞게 줄였고, 카드도 새 테이블 비율에 맞춰 가로·세로를 이전 대비 약 50%로 축소했습니다.
- 카드 뒤집기 중에는 뒷면을 먼저 보여주고 과일 면을 짧게 페이드인하여 순간적인 깜빡임을 줄였습니다.

## 리깅 아바타 파일럿

현재 정면·좌측·우측 상대 좌석에는 하나의 CC0 리깅 GLTF를 기술 검증용으로 복제해 사용합니다.

- `SkeletonUtils.clone`으로 좌석별 스켈레톤을 분리합니다.
- 각 상대가 독립적인 `AnimationMixer`와 IK 상태를 가집니다.
- 오른팔은 자기 카드 더미를 향하고, 왼팔은 중앙 종을 향하도록 CCD IK를 적용합니다.
- 종 판정은 입력 순간 처리하고, 시각적인 손 접촉은 그 뒤 애니메이션으로 표현합니다.
- 손이 종에 충분히 가까워진 경우에만 시각적인 종 반응을 발생시킵니다.
- 현재 모델은 최종 캐릭터 아트가 아니라 리깅·IK·행동 매핑 검증용입니다.

임시 리깅 모델의 출처와 라이선스는 [`ASSET-LICENSES.md`](./ASSET-LICENSES.md)를 참고하세요.

## 공개 타이밍

카드의 과일 정보는 뒤집기 애니메이션 중간에 바로 노출하지 않고 공통 reveal gate 이후 공개합니다.

현재 브라우저 봇 프로토타입에서는 동일한 로컬 타이밍 계약으로 동작합니다. 실제 여러 기기에서의 공정한 승부를 위해서는 이후 Supabase 기반 서버 권위형 `reveal_at` 전달과 종 선착순 판정이 필요합니다.

## 코드 구조

- `js/gameEngine.js`: 카드, 턴, 종 판정, 패널티 규칙
- `js/scene.js`: Three.js 장면, 카드/손/종/기본 아바타 표현
- `js/riggedAvatarPilot.js`: GLTF 리깅 파일럿, 좌석별 믹서와 행동 연결
- `js/rigIkSolver.js`: 팔 관절 체인과 CCD IK
- `js/gesture.js`: 카드 플립 드래그 제스처 판정
- `js/revealTiming.js`: 카드 공개 타이밍 계약
- `js/penaltyAnimation.js`: 오답 카드 이동 애니메이션
- `js/presentationController.js`: 추가 카메라/연출 보정
- `js/bellTouch.js`: 모바일 3D 종 직접 터치
- `js/statusPresentation.js`: 상태 문구 표현 보정

## 테스트

```bash
npm run test:fruit-bell
```

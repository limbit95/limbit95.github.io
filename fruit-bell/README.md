# 프루츠 벨 (working title)

같은 과일의 공개 합계가 정확히 5가 되는 순간 종을 먼저 치는 순발력 카드게임 프로토타입입니다.

## 이번 단계

- 4인 게임 흐름: 로컬 플레이어 1명 + 봇 3명
- 마우스 클릭으로 내 차례 카드 뒤집기
- `Space` 또는 화면 종으로 벨 입력
- 정확히 5인 과일을 판정하고 공개 카드 획득
- 오답 벨 패널티
- 입장 시 6종 동물 아바타 선택
- 마우스 포인터를 따라가는 로컬 아바타 시선
- 카드 뒤집기 / 종 치기 / 성공 / 실수의 아바타 행동 상태

## 3D 확장 설계

게임 규칙(`gameEngine.js`)과 아바타 표현 상태(`avatarSystem.js`)를 분리했습니다. 현재 화면은 DOM/CSS 기반 2.5D 프로토타입이지만, 이후 Three.js 또는 다른 WebGL 렌더러를 붙일 때 게임 규칙을 변경하지 않고 다음 상태를 그대로 렌더링 계층에 연결할 수 있습니다.

- `idle`
- `look`
- `flip-card`
- `ring-bell`
- `celebrate`
- `miss`
- `eliminated`

감정도 `neutral`, `focused`, `happy`, `embarrassed`, `sad`로 별도 관리해 향후 이모트/표정 시스템 확장을 고려했습니다.

## 비주얼 방향

특정 게임의 모델이나 에셋을 복제하지 않고, 귀여운 동물 실루엣이 명확한 3D 파티게임과 가상 테이블 게임에서 다음 요소만 벤치마킹합니다.

- 둥글고 읽기 쉬운 동물 캐릭터 실루엣
- 중앙 테이블과 종을 중심으로 한 입체적 좌석 배치
- 입력 직후 크게 읽히는 손/상체 리액션
- 게임 상태보다 캐릭터 반응이 한 박자 더 재미있게 보이는 연출

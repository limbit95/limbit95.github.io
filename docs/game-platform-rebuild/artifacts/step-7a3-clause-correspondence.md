## 1. 새 경험 요구와 기존 참조의 구분

승인 STEP6 전수표에는 기존3232 ID의 **RT 직접 목적지0**이다. 이는 누락이 아니라 RT가 승인 STEP5C R01~13의 독립 경험 요구를 소유하고 기존 공통·수명·모델/기능·Governance 의무는 그 원owner를 참조한다는 경계다. 기존 ID를 RT로 새로 재분류하지 않았다.

실제 RT1~6/최소6항목과 R13개 행의 전체규정·owner/조건·후속관측을 반영한다. 공통절차/실제모델 참조는 이전 B문맥의 공통계승 대응에서 **214원ID / 249조각**을 재사용하여 실제 owner/anchor·조건·원출처를 확인한다. 보드 전용26조각/UI171·179예시를 RT의 의무로 승격하지 않았다. DEV230 I도입은 현재Adapter 조건문맥이며 new RT MUST가 아니다. 관련scope의 전수참조이지 원3232 전체새규범본문/전수의미검토완료를 뜻하지 않는다.

원모수3232(K1198/L906/H562/I566)/305명시부모·16행58명시분할, f0 원문전체·부정/조건/예외/부모와명시f 지정범위, 원강도/의도/source·L/H/I비승격/49·B01~12비전수표를 유지한다. 적용 보드 규칙/기존scope는 [BO](../../game-platform-board-rules.md)와 승인원문에 남는다.

# STEP 3 — 일반 채팅 Sol 5.6용 보조 조사 요청문

첨부한 `step-3-auxiliary-research-input.md`를 기반으로 Game Platform vNext STEP 3의 보조 조사만 수행해줘.

역할은 Work Astra의 판단을 돕는 공식 자료·대표 사례·기술 특성 조사다. 저장소 접근을 가정하지 말고 전달 자료를 프로젝트 입력으로 사용해줘. 자료가 부족한 항목은 미확인으로 남겨줘.

## 조사 범위

입력 자료의 S3-C01~11과 S3-T01~06을 빠짐없이 색인하되 같은 근거를 반복 조사하지 마. 추가 조사는 아래 Q01~Q06에 집중해줘.

- Q01: authority/transport/prediction/rollback/correction 구분과 조건부 공식 사례
- Q02: 연결 끊김·이벤트 유실·재접속 시 state 복구와 stream/event 복구의 차이
- Q03: rollback 재실행에서 결과·보상·시청각 부수효과 중복 및 확정 결과와 예측 결과 구분
- Q04: 관전·역할 전환·중도 참가의 정보 제공 권한/초기 상태/이전 view 응답 문제
- Q05: audio/input/render/simulation/physics/network의 시간 좌표·주기 관계; 리듬과 공간 이동 사례
- Q06: host 없는 세션과 장기 비동기 진행의 제품/실행 특성; 초기 시작과 재대결을 분리

출시 활성화 중복은 실제 저장소 release 의미와 별개인 참고 사례만 필요 시 보충해줘. 플랫폼 공개 사건·서비스를 설계하거나 실제 activation을 수행하지 마.

## 자료 사용

기존 STEP 2 조사에 충분한 출처가 있으면 재사용하고 새로 확인한 부분만 명시해줘. 입력의 외부 출처 후보는 이번 Work Sol이 새로 본문 검증한 자료가 아니다. 사용하려는 주장에 필요한 원문을 확인하고 확인 날짜·버전·절을 남겨줘. 공식 문서·공식 SDK/개발자 저장소·원 연구만 근거로 사용해줘. 특정 제품의 제약/예시를 모든 게임의 필수 구조로 일반화하지 마.

## 산출물

1. 사례 / 관련 7축 / 확인 특성 / 제약·조건 / 출처 ID의 간결한 비교표
2. S3-T01~06의 참고 사실·제약·남은 질문 표
3. 공식 출처 링크와 문서 제목·판본/버전·확인일·근거 위치
4. 주장 ID별 확인된 사실 / 추론 / 미확인 구분
5. Work Astra가 판단해야 할 쟁점 목록

규칙·계약·구현 지원은 독립적임을 유지하고 모든 사례를 지원한다고 표시하지 마. 근거 없는 수치 목표나 기술 선택을 제안하지 마. 플랫폼 결정·Core 책임 확정·계약 확정·저장소 적합성/구현 지원 판정·코드 작성은 하지 마. 보조 보고서는 실행 계획과 기존 규칙을 대신하지 않는다. 결과는 사용자가 Work 방으로 전달한다.

# Splendor Phase 6 — 공개 카드 구매

## 범위

이번 단계는 공개된 개발 카드 구매만 구현한다.

- 현재 턴 플레이어만 구매 가능
- 공개 카드 1장 선택
- 영구 보너스를 적용한 실제 비용 계산
- 일반 보석 및 Gold 와일드카드 결제
- Gold는 해당 색 보석을 가지고 있어도 대신 사용할 수 있음
- 지불 토큰은 공급처로 반환
- 구매 카드의 Prestige를 점수에 반영
- 구매 카드 색상의 영구 보너스 +1
- purchased_card_count +1
- 구매한 공개 자리는 같은 Tier 덱에서 보충
- 정상 구매 후 다음 활성 플레이어에게 턴 이동
- expected_version + client_action_id 기반 동시성/중복 요청 방지

예약 카드 구매, 귀족 획득, 15점 종료 판정은 아직 이 단계에 포함하지 않는다.

## 공식 룰 기준

Space Cowboys의 현재 Splendor 규칙서 기준으로 개발 카드를 구매할 때 카드에 표시된 비용을 지불하고, 지불한 토큰은 공급처로 돌려놓는다. Gold는 임의의 Gem을 대신할 수 있고 같은 색 Gem을 보유 중이어도 Gold를 대신 사용할 수 있다. 이미 구매한 개발 카드의 보너스는 같은 색 비용을 1씩 할인하며, 공개 카드를 구매하면 같은 단계 덱에서 빈 자리를 보충한다.

## RPC

```text
splendor_purchase_faceup(
  room_id,
  card_instance_id,
  payment,
  expected_version,
  client_action_id
)
```

`payment` 예시:

```json
{
  "white": 0,
  "blue": 0,
  "green": 1,
  "red": 1,
  "black": 1,
  "gold": 1
}
```

서버는 클라이언트가 보낸 payment를 그대로 신뢰하지 않는다.

1. 카드 원래 비용 조회
2. 현재 플레이어 영구 보너스 적용
3. 실제 필요 비용 계산
4. 색상 토큰 지불량이 실제 비용 이하인지 확인
5. Gold 수량이 남은 부족분과 정확히 같은지 확인
6. 플레이어가 실제로 해당 토큰을 보유했는지 확인
7. 전부 통과했을 때만 한 트랜잭션으로 구매 처리

## Gold 선택 UI

브라우저 기본 결제는 일반 보석을 우선 사용하고 부족분을 Gold로 채운다.

사용자는 결제 패널의 `-`를 눌러 보유 중인 일반 보석 대신 Gold를 사용하도록 선택할 수 있다. Gold는 특정 색에 귀속해 저장할 필요가 없으므로 서버에는 색상별 일반 토큰 결제량과 Gold 총 결제량만 전송한다.

현재 실제 진입 파일은 `splendor-game/js/phase6PurchaseV2.js`를 로드한다. 구매 UI는 기존 예약 모듈의 placeholder 구매 버튼을 숨기고 독립된 결제 패널과 구매 버튼을 사용해 예약/구매 MutationObserver가 서로 버튼 상태를 덮어쓰지 않도록 분리했다.

## 자동 검증 완료

실제 진행 게임을 이용하되 PL/pgSQL exception subtransaction으로 변경사항을 모두 rollback했다.

- 공개 카드 구매 성공
- 구매 카드가 `purchased`로 이동하고 플레이어 소유자로 설정
- 같은 Tier 덱에서 기존 slot 보충
- Tier 덱 장수 1 감소
- 지불한 일반/Gold 토큰 공급처 반환
- 보유 중인 파랑 토큰 대신 Gold 사용 성공
- 영구 보너스 +1
- Prestige 카드 구매 시 score 증가
- 기존 영구 보너스가 실제 비용을 할인
- 동일 client_action_id 재전송 시 한 번만 처리
- 할인 후 필요한 비용보다 과다 지불 → `PAYMENT_MISMATCH`
- 다른 사람 턴 구매 → `NOT_YOUR_TURN`

## 사용자 테스트에서 볼 것

1. 현재 턴 계정에서 공개 카드 선택
2. 결제 패널에 정가/할인/실제 비용 표시
3. 보석이 충분하면 `이 카드 구매하기` 활성화
4. 일반 보석 `-` 클릭 시 Gold 자동 사용량 +1
5. 구매 후 선택 카드가 공개 자리에서 사라지고 새 카드가 보충
6. 지불한 토큰이 내 보유량에서 감소하고 공급처에서 증가
7. 카드 색상의 영구 보너스 +1
8. 카드 Prestige만큼 점수 증가
9. purchased card count +1
10. 상대방에게 턴 이동 및 양쪽 화면 실시간 동기화
11. 새로고침 후 상태 유지

# Splendor Phase 4 — 보석 획득 / 턴 진행

## 범위

Phase 4에서는 카드 구매/예약보다 먼저 가장 기본적인 턴 행동인 보석 획득을 실제 서버 로직으로 연결한다.

포함 기능:

- 현재 턴 플레이어만 행동 가능
- 서로 다른 일반 보석 가져오기
- 같은 색 일반 보석 2개 가져오기
- 금 토큰 직접 획득 차단
- 공급처 수량 차감
- 플레이어 토큰 증가
- 10개 보유 제한
- 10개 초과 시 원하는 토큰 반환
- 반환 완료 후 다음 플레이어로 턴 이동
- game version 증가 및 Realtime 동기화
- client action id 기반 중복 요청 방지

카드 구매/예약은 Phase 5에서 구현한다.

## 적용 규칙

### 서로 다른 보석

공급처에 일반 보석 색상이 3종류 이상 남아 있으면 서로 다른 색 3개를 가져간다.

3종류를 가져갈 수 없을 정도로 공급처가 소진된 상황에서는 2개 또는 1개를 가져갈 수 있다.

금 토큰은 이 행동으로 가져갈 수 없다.

### 같은 색 2개

행동 시작 시 선택한 색의 보석이 공급처에 최소 4개 있어야 한다.

예:

- 공급처 빨강 4개 → 2개 획득 가능
- 공급처 빨강 3개 → 획득 불가

### 토큰 10개 제한

금 토큰을 포함하여 턴 종료 시 최대 10개까지만 보유할 수 있다.

보석을 가져간 직후 10개를 넘으면 턴을 넘기지 않고 `return_excess` 단계로 전환한다.

플레이어가 필요한 개수만큼 원하는 토큰을 공급처에 반환하면 10개가 되고, 그때 다음 플레이어로 턴이 넘어간다.

## 서버 상태

`splendor_games.turn_phase`

- `action`: 정상 행동 선택 단계
- `return_excess`: 초과 토큰 반환 단계

`splendor_action_log`

- `client_action_id`를 게임 안에서 unique하게 저장
- 동일 요청이 재전송되어도 같은 행동이 두 번 적용되지 않도록 보호
- 브라우저 직접 조회 권한 없음

## RPC

- `splendor_take_distinct(room_id, colors, expected_version, client_action_id)`
- `splendor_take_double(room_id, color, expected_version, client_action_id)`
- `splendor_return_excess(room_id, returns, expected_version, client_action_id)`

모든 mutation은 서버에서 다음을 다시 검증한다.

1. 로그인/승인 회원
2. 현재 방 참가자
3. 진행 중인 게임
4. expected game version
5. 현재 턴 플레이어 여부
6. 현재 turn phase
7. 보석 공급량 및 행동 규칙

## 자동 검증 결과

### 정상 흐름

- A: 흰색/파랑/초록 1개씩 획득
  - A 토큰 3개 증가
  - 공급처 각 1개 감소
  - B에게 턴 이동
- B: 빨강 2개 획득
  - 행동 전 빨강 공급처 4개 조건 통과
  - 공급처 빨강 4 → 2
  - B 빨강 0 → 2
  - A에게 턴 이동
- 동일 `client_action_id` 재호출
  - 추가 토큰 차감 없음
  - action log 중복 없음

### 차단 검증

- 3종류 이상 남아 있는데 서로 다른 2개만 선택 → `MUST_TAKE_THREE_DIFFERENT`
- 현재 턴이 아닌 플레이어 행동 → `NOT_YOUR_TURN`
- 같은 색 공급량이 3개일 때 2개 획득 → `DOUBLE_REQUIRES_FOUR`
- 반환해야 할 수량과 다른 개수 제출 → `RETURN_COUNT_MISMATCH`

### 10개 제한 검증

9개 보유 중 서로 다른 보석 3개를 획득하여 12개가 된 시나리오:

1. 보석 획득 후 `turn_phase = return_excess`
2. 현재 턴 플레이어 유지
3. `must_return_count = 2`
4. 원하는 보석 2개 반환
5. 최종 보유량 = 10
6. `turn_phase = action`
7. 다음 플레이어에게 턴 이동

## 사용자 테스트 체크리스트

스플렌더 규칙을 모르더라도 아래 결과만 확인하면 된다.

1. 현재 턴인 사람에게만 보석 선택 버튼이 활성화되는가?
2. `서로 다른 보석` 모드에서 서로 다른 3개를 고르면 확정 버튼이 활성화되는가?
3. 행동 후 선택한 보석이 내 보유 보석에 추가되고 공급처에서는 줄어드는가?
4. 행동 완료 후 상대방에게 현재 턴 표시가 이동하는가?
5. 상대방 브라우저에서도 보석 수량과 턴이 자동으로 동일하게 바뀌는가?
6. `같은 색 2개` 모드에서 공급처에 4개 있는 색은 선택할 수 있는가?
7. 한 번 2개를 가져가 공급처가 2개가 되면 그 색으로 같은 행동을 다시 할 수 없게 표시되는가?
8. 금색 보석은 직접 클릭해서 가져갈 수 없게 되어 있는가?
9. 새로고침 후에도 보석 수량과 현재 턴이 그대로 복구되는가?

### 10개 초과 테스트

일반 플레이만으로 토큰을 9~10개까지 모은 후 다음 자신의 턴에 다시 보석을 획득한다.

정상 결과:

- 토큰이 10개를 넘는 순간 다른 사람에게 턴이 넘어가지 않는다.
- `토큰 N개를 반환해 주세요` 화면이 나타난다.
- 보유 중인 원하는 색을 반환 대상으로 선택할 수 있다.
- 화면에 표시된 개수만큼 선택해야 반환 버튼이 활성화된다.
- 반환 후 내 토큰이 정확히 10개가 되고 상대방에게 턴이 넘어간다.

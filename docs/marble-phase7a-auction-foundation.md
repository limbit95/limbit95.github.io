# Marble Phase 7A — Auction Foundation

Phase 7의 첫 단계는 Classic Advanced Gameplay의 경매 시스템입니다.

## 이번 범위

- 기존 Phase 6 로컬/온라인 런타임에는 연결하지 않습니다.
- 구매 거절 후 시작될 경매가 사용할 순수 규칙 모듈을 먼저 정의합니다.
- 경매 참여 자격, 시작가, 입찰, 패스, 재참여 금지, 낙찰/유찰 판정을 자동 테스트로 고정합니다.
- 게임 상태/소유권/골드 정산 및 Supabase authoritative RPC 연결은 다음 Phase 7A 통합 단계에서 진행합니다.

## 규칙 기반

- 구매를 거절한 플레이어는 해당 경매에 참여하지 않습니다.
- 파산 플레이어와 시작가를 낼 수 없는 플레이어는 참여 대상에서 제외합니다.
- 첫 입찰은 시작가 이상이어야 합니다.
- 이후 입찰은 현재 최고가보다 높아야 합니다.
- 자신의 보유 골드를 초과해 입찰할 수 없습니다.
- 패스한 플레이어는 다시 입찰할 수 없습니다.
- 현재 최고 입찰자는 패스할 수 없습니다.
- 최고 입찰자를 제외한 모든 참여자가 패스하면 낙찰됩니다.
- 아무도 입찰하지 않고 모든 참여자가 패스하면 유찰됩니다.

이 단계에서는 고정 입찰 증가 단위를 임의로 만들지 않고 최소 1 골드 이상 높은 입찰을 허용합니다. 실제 입찰 UI 단위와 타이머/순서 규칙은 서버 및 UI 연결 단계에서 결정합니다.


## 구현 완료 후 플레이테스트 UX 재검토

Phase 7A의 경매 규칙, authoritative RPC, Realtime/reconnect 및 온라인 UI 연결은 이후 단계에서 구현 완료되었습니다.

다만 2026-09-18 실제 플레이테스트 결과, **기능적으로 동작하는 것과 별개로 현재 경매 UI와 플레이 흐름은 사용성 관점에서 재검토가 필요**한 상태로 기록합니다.

이번 기록은 기존 경매 규칙을 즉시 변경한다는 의미가 아닙니다.

우선 실제 플레이에서 느낀 불편을 수집하고 다음 세 범주로 분리합니다.

- UI만 수정
- 플레이 흐름 수정
- 게임 규칙까지 수정

세부 검토 기준과 후속 요구사항은 [Auction Playtest UX Review](./marble-auction-ux-review.md)를 기준으로 관리합니다.

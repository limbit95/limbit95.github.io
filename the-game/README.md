# The Game 웹게임

원작 보드게임 **The Game**의 핵심 규칙을 웹에서 재현하는 모듈입니다.

## 개발 상태

현재 `feature/the-game-v1` 브랜치에서 개발 중이며 `main`에는 병합하지 않은 상태입니다.

### 구현된 핵심 규칙

- 숫자 카드 2~99, 총 98장
- 시작 더미 4개: 오름차순 1/1, 내림차순 100/100
- 플레이어 1~5명
- 손패 수: 1인 8장, 2인 7장, 3~5인 6장
- 덱이 남아 있을 때 턴당 최소 2장 제출
- 덱이 소진된 뒤 턴당 최소 1장 제출
- 오름차순 더미에는 더 큰 숫자 제출
- 내림차순 더미에는 더 작은 숫자 제출
- 정확히 10 차이일 때 반대 방향으로 되돌리는 규칙
- 턴 종료 시 기본 손패 수까지 카드 보충
- 필요한 최소 제출 수를 완성할 수 없으면 패배
- 덱 소진 후 손패를 모두 비운 플레이어는 턴에서 제외
- 모든 숫자 카드를 제출하면 즉시 승리

### 현재 화면

첫 화면에서 플레이 방식을 선택합니다.

- **온라인 플레이**: Supabase 방 만들기/참가/대기방
- **한 기기 플레이**: 한 화면을 넘겨가며 진행하는 로컬 완성형 프로토타입

로컬 플레이는 다음 기능을 지원합니다.

- 1~5인 인원 선택
- 현재 플레이어 손패
- 카드 선택 시 제출 가능한 더미 강조
- ±10 되돌리기 가능한 더미 별도 강조
- 턴 최소 제출 수 진행 표시
- 턴 종료 및 손패 보충
- 다음 플레이어에게 넘길 때 손패 가림
- 승리/패배 및 남은 카드 수
- 모바일 반응형 UI

온라인 대기방 1차는 다음 기능을 지원합니다.

- 기존 청파 같이 로그인 세션 공유
- 방 생성 및 최대 인원 설정
- 6자리 방 코드 참가
- 참가자/방장/준비 상태 표시
- Realtime 참가자 상태 갱신
- 준비/준비 취소
- 새로고침 후 활성 방 복귀
- 방 나가기
- 방장 이탈 시 다음 좌석 플레이어로 방장 승계

실제 카드 배분과 온라인 게임 시작은 다음 개발 단계에서 연결합니다.

## 구조

- `js/constants.js`: 규칙 상수
- `js/gameEngine.js`: 순수 게임 규칙/상태 엔진
- `js/app.js`: 모드 선택 및 로컬 플레이 UI
- `js/config.js`: 청파 같이 Supabase 설정 재사용
- `js/supabase.js`: The Game Supabase 클라이언트
- `js/multiplayerApi.js`: 대기방 RPC / Realtime API
- `js/onlineLobby.js`: 온라인 대기방 화면/상태 컨트롤러
- `tests/gameEngine.test.js`: Node 핵심 규칙 테스트
- `../tests/e2e/the-game.spec.js`: Playwright UI 스모크 테스트

## 테스트

저장소 루트에서:

```bash
npm run test:the-game
npm run test:e2e
```

GitHub Actions의 `Site static checks`에서도 The Game JS 구문 검사와 규칙 테스트를 자동 실행합니다.

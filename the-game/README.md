# The Game 웹게임

원작 보드게임 **The Game**의 핵심 규칙을 웹에서 재현하기 위한 모듈입니다.

## 개발 상태

현재 `feature/the-game-v1` 브랜치에서 1단계인 **게임 규칙 엔진**을 구현 중입니다.

### 구현된 규칙

- 숫자 카드 2~99, 총 98장
- 시작 더미 4개: 오름차순 1/1, 내림차순 100/100
- 플레이어 1~5명
- 손패 수: 1인 8장, 2인 7장, 3~5인 6장
- 덱이 남아 있을 때 턴당 최소 2장 제출
- 덱이 소진된 뒤 턴당 최소 1장 제출
- 오름차순 더미에는 더 큰 숫자 제출
- 내림차순 더미에는 더 작은 숫자 제출
- 정확히 10 차이일 때 반대 방향으로 되돌리는 규칙
- 턴 종료 시 기본 손패 수까지 카드 보충
- 더 이상 최소 제출 수를 채울 수 없을 때 패배
- 모든 숫자 카드를 제출하면 즉시 승리

## 구조

- `js/constants.js`: 규칙 상수
- `js/gameEngine.js`: 순수 게임 규칙/상태 엔진
- `tests/gameEngine.test.js`: Node 내장 테스트 러너 기반 핵심 규칙 테스트

## 테스트

저장소 루트에서 다음 명령을 실행합니다.

```bash
npm run test:the-game
```

UI, Supabase 멀티플레이, 재접속 처리는 이후 단계에서 이 엔진 위에 추가합니다.

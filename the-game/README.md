# The Game 웹게임

원작 보드게임 **The Game**의 핵심 규칙을 웹에서 재현하기 위한 모듈입니다.

## 개발 상태

현재 `feature/the-game-v1` 브랜치에서 **핵심 게임 엔진 + 로컬 플레이 UI**까지 구현되어 있습니다.

### 구현된 규칙

- 숫자 카드 2~99, 총 98장
- 시작 더미 4개: 오름차순 1/1, 내림차순 100/100
- 플레이어 1~5명
- 손패 수: 1인 8장, 2인 7장, 3~5인 6장
- 덱이 남아 있을 때 턴당 최소 2장 제출
- 덱이 소진된 뒤 턴당 최소 1장 제출
- 오름차순 더미에는 더 큰 숫자 제출
- 내림차순 더미에는 더 작은 숫자 제출
- 정확히 10 차이일 때 반대 방향으로 되돌리는 규칙
- 턴 종료 시 기본 손패 수까지 카드 보충
- 더 이상 최소 제출 수를 채울 수 없을 때 패배
- 모든 숫자 카드를 제출하면 즉시 승리

### 구현된 로컬 UI

- 1~5인 인원 선택
- 현재 플레이어 손패 표시
- 카드 선택 시 제출 가능한 더미 강조
- ±10 되돌리기 가능 더미 별도 강조
- 턴당 최소 제출 수 진행 표시
- 턴 종료 및 카드 보충
- 여러 명이 한 기기를 사용할 때 다음 플레이어 손패 가림 화면
- 승리/패배 결과 화면 및 남은 카드 수 표시
- 모바일 대응 레이아웃

## 구조

- `index.html`: 게임 화면
- `css/style.css`: 게임 전용 스타일
- `js/constants.js`: 규칙 상수
- `js/gameEngine.js`: 순수 게임 규칙/상태 엔진
- `js/app.js`: 로컬 플레이 UI 상태 및 이벤트 연결
- `tests/gameEngine.test.js`: Node 내장 테스트 러너 기반 핵심 규칙 테스트
- `../tests/e2e/the-game.spec.js`: Playwright 기반 브라우저 스모크 테스트

## 테스트

핵심 규칙 테스트:

```bash
npm run test:the-game
```

전체 Playwright E2E 테스트:

```bash
npm run test:e2e
```

다음 주요 단계는 실제 온라인 멀티플레이를 붙이기 전에 로컬 한 판의 UX와 예외 상황을 더 검수하는 것입니다. 이후 Supabase 기반 방 생성, 비공개 손패, 턴 동기화, 재접속 처리를 추가합니다.
